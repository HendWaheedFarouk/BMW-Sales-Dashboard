# BMW Sales Dashboard

An interactive Power BI dashboard analyzing BMW sales performance across different models, with a dedicated page for each model.

## Dashboard Overview

The report has a **home page** with navigation buttons, plus **6 model pages** (X3, X6, i8, M5, 7 Series, and i3). Each page is filtered to its own model and follows the same layout.

### KPIs
- **Sales Volume**: total units sold
- **Average Price (USD)**
- **Average Engine Size**
- **Average Mileage (KM)**

### Visuals
- **Sales Volume by Region**: bar chart
- **Sales Volume by Transmission**: donut chart (Manual vs. Automatic)
- **Sales Volume by Fuel Type**: bar chart (M5 and 7 Series pages)
- **Sales Volume by Sales Classification**: bar chart (all other model pages)

## Features
- Navigation buttons on the home page to jump to each model's dashboard
- Year slicer covering the last 4 years (2021-2024) with a "Select all" option
- Every page is filtered to a single model
- Left and right arrow buttons to navigate between model pages (previous / next)

## Tools
- Power BI Desktop
